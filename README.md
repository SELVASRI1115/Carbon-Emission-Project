# Carbon Emission Audit and Sustainability Tracking System

## Project Overview

The Carbon Emission Audit and Sustainability Tracking System is a full-stack web application developed to monitor, manage, and audit carbon emissions generated by industrial and organizational activities.

The system helps organizations maintain sustainability records and improve environmental transparency by digitizing emission tracking and audit workflows.

This project does not use Artificial Intelligence. It relies on predefined emission calculations, structured workflows, and role-based access control.

---

## Objectives

* Track carbon emissions from various activities
* Support sustainability initiatives
* Reduce manual calculation errors
* Maintain emission audit records
* Provide centralized environmental reporting
* Improve transparency in carbon monitoring

### Emission Tracking

Vendor can:

* Add emissions
* View emissions
* Delete emissions
* Monitor status

Emission formula:

Total Emission = Activity Data × Emission Factor

Example:

Activity Data:

500 kWh

Emission Factor:

0.82 kg CO₂/kWh

Result:

500 × 0.82

Total Emission:

410 kg CO₂

## Project Workflow

1. User registers into the system

2. User logs in

3. JWT token generated

4. User enters dashboard

5. Admin creates emission categories

6. Vendor submits emission data

7. System calculates total emissions

8. Emission data stored in database

9. Auditor reviews submissions

10. Audit results stored

11. Dashboard displays summary information
